# Prática Avaliada 1 - Engenharia de Software I

## Sobre o Projeto

Este repositório contém a resolução da Prática Avaliada 1 da disciplina **Engenharia de Software I**.

A atividade tem como objetivo aplicar conceitos estudados sobre:

- Manifesto Ágil
- Métodos Ágeis
- Scrum
- Extreme Programming (XP)
- Kanban
- Design Simples
- Princípio YAGNI (You Aren't Gonna Need It)

O cenário proposto simula a startup **AgileTech Solutions**, responsável pelo desenvolvimento de uma plataforma para gestão de projetos ágeis.

## Questão 1 – Análise de Processo e Manifesto Ágil

Arquivo:

```text
analise-processo.md
```

Conteúdo desenvolvido:

- Aplicação dos 4 valores do Manifesto Ágil
- Comparação entre abordagem ágil e modelo cascata
- Práticas ágeis recomendadas para a empresa
- Programação em Pares (Pair Programming)
- Desafios de equipes remotas e EAD
- Dificuldades essenciais de Brooks
- Estratégias de mitigação utilizando métodos ágeis

---

## Questão 2 – Processo XP e Scrum

Arquivo:

```text
processo-xp-scrum.md
```

Conteúdo desenvolvido:

- Estruturação do processo utilizando XP e Scrum
- Definição de práticas de XP
- Integração entre XP e Scrum
- Fluxo semanal da equipe
- Cronograma de Sprint de 2 semanas
- Comparação entre Scrum e Kanban
- Utilização de GitHub Projects para gerenciamento das atividades

Quadro Kanban criado para representar o fluxo de trabalho da equipe:

- Backlog
- Ready

- Done

## Questão 3 – Design Simples e YAGNI

Arquivos:

```text
analise-yagni.md
src/usuario_simples.py
```

Conteúdo desenvolvido:

- Identificação de elementos desnecessários no código original
- Aplicação do princípio YAGNI
- Simplificação das classes
- Remoção de complexidades desnecessárias
- Manutenção das funcionalidades essenciais:
  - Cadastro de usuários
  - Login
  - Listagem de usuários
  - Validação de email duplicado
  - Armazenamento seguro de senha com hash
